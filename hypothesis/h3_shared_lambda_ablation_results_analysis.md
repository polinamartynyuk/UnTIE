# Результаты H3 shared-lambda ablation

Дата: 2026-10-07  
Запуск: `artifacts/qa_chunk_selection_h3_shared_lambda_ablation/run_20261007_01`

## Постановка

Для каждого датасета выбирается одно общее `λ` для seeds 42, 43 и 44:

`prediction = H2 + λ × (H3 − H2)`.

Кандидаты: `λ ∈ {0, 0.25, 0.5, 0.75, 1}`. Для каждого λ и seed пороги
utility/harm выбираются внутри document-grouped OOF. Затем λ выбирается по
среднему OOF Token F1 трёх seeds. После выбора один λ применяется ко всем
seeds датасета; модели и пороги остаются seed-specific.

Эксперимент является post-hoc абляцией: финальный TEST уже был открыт до его
постановки. TEST-метки не используются при выборе λ, но итог требует будущей
независимой проверки.

## Корректность

- Выполнение завершено за 58.6 секунды со статусом `COMPLETED`.
- Покрытие: 182 вопроса SciREX, по 30 SciER-128/384, 100 RuSERRC и 28 SciMDIX;
  для каждого вопроса имеются три seeds.
- Исходный финальный benchmark и предыдущая seed-specific BLEND-абляция не
  изменились: обе hash-проверки имеют статус `PASS` и пустой список изменений.
- Перед запуском прошли 8 целевых тестов.

## Family-balanced bootstrap

Использован парный document bootstrap на 10 000 итераций с одинаковым весом
четырёх семейств и связанным ресемплированием SciER-128/384.

| Контраст | Δ Token F1 | 95% CI |
|---|---:|---:|
| Shared λ vs P2 | **+1.5913** | **[+0.0821; +3.0020]** |
| Shared λ vs P4 | +0.8242 | [−0.1506; +2.8741] |
| Shared λ vs предыдущий BLEND | **+0.9445** | **[+0.3494; +1.7309]** |

Получено статистически положительное агрегированное преимущество над P2 и
предыдущим seed-specific BLEND. Интервал сравнения с P4 пересекает ноль,
поэтому превосходство над исходным H3 пока не доказано.

- **SciER-128:** shared λ, P4 и предыдущий BLEND полностью совпали.

## Вывод

Гипотеза подтверждена в рамках post-hoc абляции. Dataset-level выбор одного λ
по среднему TRAIN-OOF трёх seeds оказался лучше отдельного выбора λ для каждого
seed. Он автоматически выбрал H2 для SciMDIX и H3 для английских датасетов,
сохранив концепцию единого смешивания без специальных языковых правил.

Получившаяся система почти совпадает с эмпирическим выбором лучшего из H2/H3
по TEST: единственный недобор — 0.2745 пункта на RuSERRC, где λ=0.5 дал
поведение P2 вместо немного лучшего P4. Family-balanced результат shared λ
равен 56.7917 против 56.8603 у недоступного TEST-oracle выбора H2/P4.

При этом текущий результат нельзя объявлять окончательным улучшением финального
метода: идея была сформулирована после просмотра поведения SciMDIX, а TEST уже
был открыт. Корректный следующий шаг — зафиксировать shared-lambda правило и
подтвердить его на новом независимом датасете или новом заранее закрытом split.
