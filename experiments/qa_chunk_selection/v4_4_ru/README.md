# V4.4-RU

Отдельный русскоязычный replay протокола V4.4. Пакет читает завершённый артефакт
`qa_chunk_selection_v4_4_ru_q5_b0_20260912_172431` и всегда пишет в новый каталог.
Английский пакет `v4_4` и все предыдущие результаты остаются неизменными.

Проверка входов без запуска:

```bash
python3 -m experiments.qa_chunk_selection.v4_4_ru --check-only
```

Фоновый запуск:

```bash
bash experiments/qa_chunk_selection/v4_4_ru/launch_background.sh
```

Скрипт печатает PID, путь журнала и каталог результата. Журнал обновляется после
каждой стадии, внутри длинных циклов и каждые 30 секунд.
